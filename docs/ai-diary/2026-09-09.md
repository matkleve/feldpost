## Mistakes / lessons

- Assumed `--include` on `ng test` would scope *compilation*, not just *execution* — it doesn't; `tsconfig.spec.json` includes `src/**/*.spec.ts` unconditionally, so any spec file anywhere in the app can block every other spec file from type-checking. Caught this before silently expanding scope into unrelated subsystems; used `npx vitest run <file>` directly (bypassing Angular's builder, which does its own whole-program TS check) to get a real, isolated red→green cycle for the one Sensitive-class fix that needed it.
- The `lint-specs-full.txt` discovery is worth remembering for future audits of this repo: a captured CLI-output file committed to git root will silently go stale and can end up quoted as ground truth by anyone (including an earlier version of the same audit plan) who doesn't re-run the command it captures.
